This tutorial introduces UVA RC GenAI, a secure, locally hosted generative AI platform for UVA researchers. The service offers users a high-performance alternative to commercial AI tools with all data processed in-house at UVA. You will learn to access the service through the Open WebUI browser interface for conversational research assistance, document and image analysis, and via API for programmatic workflows using Python, Jupyter notebooks, and agentic tools. The session covers authentication, policies, security limitations, and provides working code templates for real-world research use cases. No prior AI or API experience is required.
